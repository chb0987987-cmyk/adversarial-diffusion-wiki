# 自然性對抗貼片入門：從生成模型到偽陽性研究

**[開啟簡報.html](簡報.html)**

14 頁、20 分鐘。聽眾為指導教授與實驗室同學；內容依五篇 LLM Wiki 來源，從基本概念走到方法討論、局部偽陽性研究應用，以及 Wiki／workflow／反思。

## 使用方式

- 以瀏覽器開啟「簡報.html」。內容、12 張 SVG 圖、講稿與 61 項證據均嵌入單一 HTML，不依賴外部套件。
- 方向鍵、Page Up／Page Down 換頁；Home／End 到首尾頁。
- O：目錄；N：講稿；R：連續閱讀；F：全螢幕。也可使用畫面按鈕。
- 引用按鈕顯示證據摘要、原文位置與閱讀限制；「來源」列出全部五篇。
- 「放大圖示」開啟圖稿；列印採橫向樣式。原生列印排版與實際全螢幕仍需瀏覽驗收。
- Wiki 相對連結需保留完整專案目錄；原始 PDF 連結需登入並連線。

## 實際驗證範圍

結構、JavaScript 語法、引用 ID、來源覆蓋、SVG XML 與原始檔保存已檢查。94 項程式行為檢查在輕量 DOM 模型中執行，涵蓋換頁、目錄、講稿、來源、圖稿放大與邊界；不代表原生瀏覽器已完成排版、焦點、列印或全螢幕驗收。

瀏覽器啟動受到目前環境的 Windows IPC／程序權限限制，實際 HTML 渲染與操作驗收仍受阻。三張關鍵方法／流程 SVG 已另外渲染預覽並檢視；這不替代 HTML 整頁驗收。

五篇來源維持 partial；原圖表、完整公式與部分外部附錄尚未核對。本簡報的場景與方法圖為教學示意，沒有加入假造的攻擊實驗或分數。
